# Plan: Privacy Policy Implementation and Push to Dev

## Goal
Add a comprehensive Privacy Policy page (`/privacy`) detailing user data collection, usage, storage, and third-party integrations (Better Auth, MongoDB, Resend, Google Analytics) for Kanscout, display a site-wide Footer linking to it, and push changes to the `development` branch.

## Current Context / Assumptions
- Framework: Next.js 16 (App Router) with Tailwind CSS v4 and Lucide React.
- Authentication & Data: Uses Better Auth with MongoDB, Google OAuth, and Resend for transactional verification emails.
- Analytics: Google Analytics (`gtag` with ID `G-JXE1NKJV88`) loaded in `app/layout.tsx`.
- Current Navigation: `Navbar` exists in `app/layout.tsx`, but no `Footer` exists currently.
- Git Branch: Current working branch is `development` (`origin/development`).

## Architecture / Proposed Approach
1. Implement a responsive, accessible Privacy Policy page at `app/privacy/page.tsx` with structured sections (Data Collected, How We Use Data, Third-Party Services, Cookies & Analytics, Data Security, User Rights, Contact Us).
2. Create a global `Footer` component at `components/footer.tsx` with links to `/privacy`, brand identity, and copyright info, integrated into `app/layout.tsx`.
3. Validate with Next.js lint (`npm run lint`) and build (`npm run build`).
4. Commit changes with a clean commit message and push to `origin/development`.

### Task 3: Integrate Footer into Root Layout
**File:** `app/layout.tsx`

**Action:** Import and include `<Footer />` inside `app/layout.tsx`.

```tsx
import type { Metadata } from "next";
import { Geist, Geist_Mono } from "next/font/google";
import "./globals.css";
import Navbar from "@/components/navbar";
import Footer from "@/components/footer";
import Script from "next/script";

const geistSans = Geist({
  variable: "--font-geist-sans",
  subsets: ["latin"],
});

const geistMono = Geist_Mono({
  variable: "--font-geist-mono",
  subsets: ["latin"],
});

export const metadata: Metadata = {
  title: "Kanscout - Visual Kanban Board for Job Search & Application Tracking",
  description: "Kanscout is an intuitive Kanban board for looking for jobs and tracking your job applications from start to offer.",
};

export default function RootLayout({
  children,
}: Readonly<{
  children: React.ReactNode;
}>) {
  return (
    <html
      lang="en"
      className={`${geistSans.variable} ${geistMono.variable} h-full antialiased`}
    >
      <head>
        <Script
          src="https://www.googletagmanager.com/gtag/js?id=G-JXE1NKJV88"
          strategy="afterInteractive"
        />

        <Script id="google-analytics" strategy="afterInteractive">
          {`
            window.dataLayer = window.dataLayer || [];
            function gtag(){window.dataLayer.push(arguments);}
            gtag('js', new Date());

            gtag('config', 'G-JXE1NKJV88');
          `}
        </Script>
      </head>
      <body className="min-h-full flex flex-col">
        <Navbar />
        <div className="flex-1">{children}</div>
        <Footer />
      </body>
    </html>
  );
}
```
